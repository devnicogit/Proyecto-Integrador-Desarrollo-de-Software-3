# Anexo 3 — Validación del Instrumento por Juicio de Expertos

## Descripción

Para garantizar la validez de contenido del instrumento de recolección de datos (fichas de registro de IID, CHR, TDE y cuestionario UTAUT), se aplicó el **método de juicio de expertos**. Se sometieron los instrumentos a evaluación por **tres (3) expertos** con grado académico de Magíster o Doctor y experiencia en investigación y/o desarrollo de software para el sector logístico.

Cada experto evaluó cuatro criterios en una escala de 1 a 5, donde 1 = Deficiente, 2 = Regular, 3 = Bueno, 4 = Muy Bueno, 5 = Excelente.

### Criterios evaluados

| Criterio | Descripción |
|---|---|
| **Claridad** | El instrumento está formulado con lenguaje claro y comprensible. |
| **Coherencia** | Los ítems corresponden a las dimensiones e indicadores planteados. |
| **Relevancia** | Los ítems son importantes para evaluar la variable. |
| **Suficiencia** | Los ítems son suficientes para medir la dimensión a evaluar. |
